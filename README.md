# Transfer Pricing Benchmarking Tool

A comparable-company benchmarking tool that replicates the core mechanics of a
Transactional Net Margin Method (TNMM) study under the OECD Transfer Pricing
Guidelines and U.S. Treas. Reg. §1.482-5.

> **Status:** under active development. Full documentation (methodology,
> usage, disclaimer) lands once the analysis pipeline is complete — see the
> project plan in the repository's commit history for the build sequence.
